# 全局记忆的数据与操作边界

## 单一权威库

日记、画像和月摘要位于当前用户的 `~/.agents/memory-store/memory.db`。权威内容写入只能通过存储引擎的具体 `plan` / `commit`，不能直接改写库文件或绕过写入通道修补用户库。

工作目录不选择数据根，不要求项目表或登记。库内没有目录表或指纹核对作为读取、保存的前置条件。不自动迁移、复制或双写用户内容。

## 生命周期与历史

- 新全局记录没有必需项目字段。旧日记、旧摘要及来源标签可读，读取不重写文件。
- 当前全局同 `rule_key` 仅允许一个有效版本。历史来源的同名规则保留各自命名空间，不自动合并或提升适用范围。
- 新全局规则的同键更新仅自动替代当前全局旧规则；替代历史来源或不同键目标必须显式指定有效记录 ID 和理由，并展示完整影响。
- 替代保留旧 ID、日期和正文，关联真实后继，不允许循环或悬空引用。当前规则查询排除历史版本，历史和月度来源仍可读取。
- 普通日记来源使用真实 ID；非规则记录不参与有效版本替代，但可处于 `active`／`resolved`／`archived`。关闭已有活跃记录须显式提供 `status_updates`（目标 ID、目标状态、理由）；`resolved`／`archived` 不进入当前项目近况，仍可按 ID 读取或检索。画像替换不删除日记来源。
- 新画像只用全局或所选领域作用域；旧项目画像不自动变为全局偏好。

## 有用性标注

标注事件表独立于权威正文、词项与计划版本。它按记录与会话哈希保存去重标注和时间，不保存正文、理由或原始会话 ID；哈希不等于匿名化。

标注由模型显式发起，不接受外部计数或时间；事件写入库内事件表，不初始化库、不创建技术文件。标注只在检索排序中参与有界乘子，不参与常驻注入资格，不代表理解、采用或正确性。

标注写入在写事务内完成，库忙时报告，不重试。已启动写入不因停用或取消而撤销；清空事件表即整体回滚。

## 明确删除

仅在用户明确要求忘记、删除或纠错时准备 `plan delete`。展示完整目标正文、真实 ID、日期、历史来源及受影响日记关联、画像来源、标注事件和月摘要。

提交在同一事务中删除目标、清理悬空引用及对应标注事件；删除后继不会使旧决定复活。画像已确认正文不因来源删除自动消失。摘要撤回不等于语义重建。

删除计划绑定完整目标标注范围，提交时新增的对应标注也包括在内；缺少范围的旧计划拒绝执行。

删除不覆盖外部 Git、备份、云同步或其他设备，也不授权操作项目内文件。

## 计划、并发与恢复

计划协议版本为 4，24 小时失效。旧项目语义计划拒绝提交，须重新生成、展示和确认，不批量改写旧缓存。

`plan` 写入库内待确认表，`commit` 才修改权威数据。候选、引擎、源内容或所属会话／分支变化后旧确认失效；`--approved` 只是引擎内部标记，不是身份认证；扩展侧的提交由写入闸门放行，不代表用户逐份确认。

多用途计划按当前状态依次生成。提交在同一写事务内核对库变更序号，写入正文与词项；外部绕过协议的写入不受其保护。取消已启动提交不等于撤销，结果未确认时不自动重试。

查询不建库、不重建词项、不自动迁移；缺库、版本不符、权限错误、库忙和无命中分别报告。

词项表是日记与月摘要的词法派生数据，与正文在同一事务内写入，不是第二份正文。库版本或引用关系不一致时停止，不回退全历史扫描。

`validate`、`integrity`、`reindex`、`migrate` 与初始化都不是默认收尾。重建只重算派生词项，实际运行须单独批准；本 Skill 不自动执行这些操作。
