# 真机 GUI 验证

### 驱动窗口被辅助访问间歇拒绝；停 dev 后 Electron 主进程残留
现象：真机验证 Electron 界面时，用宿主系统脚本驱动窗口（点击、读窗口位置）会间歇被辅助访问权限拒绝，同一会话内首次可能成功、之后被拒；全屏截图截到的是前台其他应用窗口；停掉 dev 脚本后 Electron 主进程仍存活，再次启动出现双实例。
根因：辅助访问授权对系统脚本工具不稳定（待核实）；dev 生命周期脚本退出不级联终止它启动的 Electron 主进程。
处置：窗口驱动与截图统一走 Orca computer-use CLI（`orca computer list-windows/click`，以 pid 定位应用，元素索引易过期、从返回 treeText 现取）；截图按窗口坐标区域取，不截全屏。停 dev 分两步：先停 dev 脚本，再按 Electron 可执行路径 pgrep 收尾，以 pgrep 为空确认。
排除：依赖宿主系统的窗口自动化工具（授权不稳定）；未安装专用的坐标点击工具时不要假设其存在。
