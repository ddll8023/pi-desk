# Sidecar 派生控制台窗口

### 对话启动时，用户级扩展弹出控制台

现象：桌面对话启动后出现额外控制台窗口，项目启动器已对 Pi 进程设置 windowsHide。

根因：已定位的窗口来自用户级 context-mode 扩展。可见窗口 PID、脚本入口与父进程链共同指向 Electron → Pi → context-mode 的 server.bundle.mjs；扩展的 MCP 桥接启动服务器时未隐藏控制台。项目携带独立 Pi executable，不代表其用户级扩展配置也独立。

处置：该案例通过 Pi 官方卸载入口移除 context-mode，不修改项目启动器。处理共享用户配置时注意其他 Pi 客户端也会受影响。

排查边界：再次出现时按可见窗口 PID、脚本入口与父子链定位；不能仅凭后台进程数量或较晚开始的采样归因，也不能将此案例推广为所有控制台窗口的原因。
