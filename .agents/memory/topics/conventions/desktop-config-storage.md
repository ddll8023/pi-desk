# Desktop 配置存储

### desktop-config.json 是整文件写入，且假定单实例

约定：配置字段统一走 `DesktopConfigStore` 的同一份文件写入；不引入第二个写入者（第二个窗口、第二个 Electron 进程、外部脚本直接改这个文件）。应用已用 `requestSingleInstanceLock()` 拦住第二个实例，并在写入前比对加载时记录的文件标识，不一致就放弃本次保存。

适用：新增配置字段、新增任何写配置的路径，以及需要多实例或多窗口的验证。

原因：实测两个实例共享这份文件时，后写者会用自己的内存列表覆盖磁盘，项目记录被写回或凭空消失（已实际发生一次数据丢失，两个项目记录丢失且没有备份）。
