# 第五阶段：Desktop 产品能力

[开发总览](../development.md) · [上一阶段：Authentication](04-authentication.md)

## 目标与边界

完善桌面使用体验、恢复能力和应用更新。保持 Pi 版本显式固定，Desktop 更新与所携带 Runtime 协同，不允许独立自动切换到最新 Pi。

本阶段不重做基础 Project、UI 偏好或 Runtime 生命周期，也不扩展为 IDE。

## 依赖

- 已有稳定 Project / Session / Runtime 归属与轻量配置。
- 实际发行包、签名、资源布局与更新平台条件在相应任务中核实，不从开发机路径推断安装后行为。
- 多窗口改变 Runtime 所有权与通知范围，需要在开发前明确，不提前默认每个窗口独立启动一个 Pi。

## 任务拆分

### P5-01 崩溃恢复

**目标**：在意外退出后恢复可理解的项目与会话状态。

**范围**：依赖 Pi 已持久化 Session 恢复上下文，明确中断操作与未知结果，提示用户选择继续或重新发起。处理 Desktop / Pi 异常退出的不同情况，不自动重放 prompt 或工具操作，不把未收到 response 当作未发生副作用。

**依赖**：第一阶段生命周期与第二阶段 Session；不新建聊天历史数据库。

### P5-02 最近项目完善

**目标**：完善已有最近项目入口与失效目录体验。

**范围**：最近项目导航、排序、失效路径提示与移除记录；复用第二阶段 Project 数据。移除最近记录不删除项目目录或 Pi Session，重新定位目录不静默继承不适用的信任决定。

**依赖**：第二阶段 Project 与第三阶段 Trust。

### P5-03 全局快捷键与托盘

**目标**：提供可配置的快速打开入口与清晰桌面生命周期。

**范围**：全局快捷键、冲突提示、托盘操作，以及显示、隐藏、关闭窗口、退出应用的职责划分。macOS Dock / 菜单栏与 Windows 任务栏行为分别考虑；不能默认关闭窗口等于隐藏或让所有用户常驻后台。

**依赖**：Runtime 退出管理与 UI 偏好；快捷键及常驻行为作为用户可见决策确认。

### P5-04 通知

**目标**：在应用不处于前台时提供有用且可控的状态提醒。

**范围**：任务完成、需要交互和失败等通知，系统权限、用户开关、重复抑制与点击回到正确上下文。通知内容避免泄露提示词、文件内容、工具输出或凭据，不在通知中自动批准 Extension 请求。

**依赖**：运行状态与 P5-03 窗口显示机制；Extension 通知语义复用第三阶段边界。

### P5-05 多窗口

**目标**：支持多个窗口而不破坏 Project / Runtime 的唯一归属。

**范围**：由 Electron 主进程拥有窗口与 Project / Session / Runtime 的映射、Runtime 生命周期及临时消息投影；各渲染进程的 Pinia 只保存自身展示状态。明确共享或独占归属、跨窗口协调、订阅同步、资源释放与关闭行为，不因打开新窗口自动启动另一个 Pi。

每个窗口通过受限 preload API 操作，主进程校验可信窗口、顶层 frame 来源及 Runtime 归属，事件只定向发送给有权订阅的窗口，不以广播全部敏感事件实现同步。分别处理窗口关闭、渲染进程异常、最后一个控制窗口释放和应用退出；第一阶段单窗口的关闭规则不能直接作为多窗口所有权规则。

**依赖**：稳定 Project / Session 生命周期、P5-03 窗口行为；是否允许多个活动 Runtime 在本任务单独讨论，不自动扩大为多 Agent 调度。

### P5-06 自动更新

**目标**：通过明确且安全的 Desktop 更新流程发布应用与固定 Pi Runtime。

**范围**：更新通知、下载与签名机制、用户确认、活动操作处理，以及 Desktop / Pi / 配套资源作为一致发行版本更新。Pi 升级是显式版本变更，不调用运行时 latest 或 Pi 自更新绕过 Desktop 分发。

**依赖**：实际 Windows/macOS 发行方式、资源布局与更新基础条件；复用 P5-01 中断恢复，不在更新时静默丢弃活动会话。

## 推进顺序

```text
P5-01 → P5-02 → P5-03 → P5-04 → P5-05 → P5-06
```

以上是默认产品推进顺序，不表示所有后项都有前项的硬依赖；不为了顺序提前增加无用途框架。

## 不做项

- Git GUI、Terminal、完整文件管理器、Workspace、任务编排或多 Agent。
- 云端同步、遥测平台、远程 Agent RPC 服务。
- 自动重放有副作用的操作、独立自动升级 Pi。
- 未经用户选择的常驻、自启动或全局快捷键接管。

## 待决策事项

- 崩溃后哪些状态可以可靠恢复，未确定副作用如何提示。
- 关闭主窗口、后台运行与退出应用的产品行为。
- 通知触发条件、可见内容与系统权限交互。
- 多窗口是否共享 Runtime、是否允许多个活动项目以及并发资源边界。
- Windows/macOS 分发、签名、更新源与活动 Runtime 下的更新策略。
