# 手机访问

模块 ID：`lan-remote`。返回 [总览](../项目结构文档.md)。

## 职责与入口

负责局域网手机访问入口的启停、扫码自动登记设备、手机网页资源挂载，以及已登记项目内会话的后台新建与受限远程接入。桌面控制入口为设置页「手机访问」分节；开启后自动识别局域网地址、分配端口并展示二维码，手机扫码即进入项目页面，无需配置代理、证书或逐项目授权。手机在项目会话列表选择已有会话，或通过「新建会话」进入空白对话，首次提交对话输入时才创建实际会话；输入坞提供斜杠命令候选、本地新建与受限压缩入口。

执行仍在电脑上：本模块不另建会话运行时，也不隔离项目文件。手机页面不提供文件、终端、Git 与设置入口，也不渲染生成式界面。默认不监听，每次启动应用都需要显式开启。

## 关键调用链

1. 桌面开启入口：用户显式开启后，主进程自动识别局域网地址并分配 HTTP 监听端口，设置页自动展示二维码；关闭入口或应用退出时收敛连接，不自动恢复监听。控制与状态契约见 `src/shared/lan-remote-api.ts`。
2. 扫码连接：手机优先复用浏览器已有设备身份，无有效身份时自动兑换链接中的一次性连接码，设备名称由服务端识别，无需填写或确认。凭证通过 HttpOnly Cookie 回到手机，配置中只保存设备身份与凭证摘要；二维码过期或被使用后由设置页自动更新。
3. 新建或接入会话：手机显示全部已登记项目，可选择已有会话或新建空白对话；空白对话只保存页面草稿，首次提交对话输入时才在电脑后台创建并提交首条消息。后台新建与打开复用会话授权链，复核设备、项目与信任，不改变桌面前台，也不清扫或占用桌面空白会话。
4. 命令分流：输入坞按阶段请求预读或绑定资源，选择候选只填充输入；`/new` 在页面进入空白对话，`/compact` 经固定目标调用 SDK 压缩，技能、模板与扩展命令仍交给 SDK 解析。
5. 同步：连接先建立事件观察再读取权威快照，之后按序号应用增量；增量失效或有缺口时重新取快照，不由手机端自行补齐。
6. 写操作：新建与首条消息共用请求身份，其余发送、停止、压缩与问题回应固定会话与绑定代际，均按原请求去重；结果未知时页面保留原请求等待用户显式重试或核对，不自动重发。

## 状态与边界

设备身份是访问控制真源：撤销立即关闭该设备的连接与事件流，重新配对会改变请求去重所依据的设备身份，旧写请求不会迁到新身份执行。已连接设备可访问全部已登记项目，但不能指定任意会话文件或主机路径。

手机页面是独立的页面入口，只经同源局域网 HTTP 接口工作，不加载 Electron 桥接，也不把桌面 Store 当作状态源。每条连接各自维护同步水位，慢连接只影响自身，通过背压与断流收敛，不阻塞桌面对同一会话的展示。会话本身仍由 SDK 与主进程持有；手机断开不中断正在运行的任务，重新连接后按权威快照重建。

手机可阅读会话图片上的编号、整图说明及各标记的绑定说明，不提供图片标注编辑入口；资料的提交与历史归属见[会话与聊天](sessions-chat.md#状态与边界)。

新对话草稿在当前页面按项目保留，点击新建本身不建立执行占用；首次提交对话输入时才创建真实会话。创建成功后即使首条消息明确被拒绝，也返回实际会话身份并保留输入，后续只向已创建会话重试发送，不再次新建；首条消息结果仍不确定时继续保护原请求。尚未拿到实际身份时可查看原项目会话列表，已知身份后可查看原会话；重试复用原请求，核对后解除保护不会自动重发。草稿与待核对请求只保留页面内存，不跨刷新或应用重启恢复。

输入以 `/` 开头且尚无空白时显示可搜索的命令候选；点击或 Tab 只填充命令并保留追加参数的位置，不直接执行，方向键选择、Esc 收起。手机回车仍用于换行，Ctrl+Enter 提交。新对话仅预读技能，不为候选建立执行会话、加载扩展或连接 MCP；绑定后以当前会话已加载的技能、模板和扩展命令替换预读清单。候选不携带资源文件路径或正文；读取失败独立提示，不把失败当作没有资源。刷新候选可重新预读，绑定清单仍以会话已加载资源为准，不代替资源重载。

移动端 `/new` 与新建入口一致，只进入空白对话，保留原会话与电脑上的任务，不执行桌面标签内结束原实例的动作。`/compact` 可追加摘要说明，只对已绑定、同步且空闲的当前会话提交压缩，运行目标与空闲条件还由后台和 SDK 复核。服务端拒绝把这两个界面命令通过普通新建或消息接口提交给模型。压缩失败保留原命令；完成后只清空仍属原会话且未被改写的输入，结果未知时沿用原请求保护，不自动重复压缩。

后台新建与打开不切换桌面当前项目或前台，不清扫或占用桌面空白会话，也不允许中断或重载。项目资源需要信任决定而尚无决定时，由桌面端先处理，手机不代替用户授予信任；候选预读在尚需信任决定时按未信任范围读取。

手机通过局域网 IPv4 地址直接访问电脑，地址识别优先使用实体网卡的私有地址，其他网卡地址作为备用；地址范围由 `src/shared/lan-remote-api.ts` 的 `isLanAddress` 定义。服务检查真实连接来源、访问地址与同源请求，不根据转发头授予设备身份。

手机与电脑需处于可互相访问的局域网，电脑与应用需保持运行；入口使用 HTTP，不提供传输加密或公网中继。连接地址、监听状态与一次性连接码只保留在内存中，不恢复监听；设备身份与凭证摘要由 `DesktopConfigStore` 持久化。

已连接手机能驱动 Agent 在电脑上的已登记项目中执行操作，不是只读预览；设备校验与会话能力白名单在后台执行，不增加扫码后的确认步骤。
