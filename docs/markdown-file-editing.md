# Markdown 文件预览与编辑

工作区文件标签提供「源码」和「预览」两种视图。可安全编辑的 Markdown 在预览中保留排版并直接接受输入，不需要开启额外的编辑开关。

## 预览编辑

- 点击正文放置光标，可连续编辑段落、标题、引用和列表，也可跨块选择、删除、复制与粘贴。
- 普通段落按 Enter 换段；代码块内按 Enter 换行，不作为提交操作。
- 列表中按 Enter 续项或在光标处拆分条目；空项的退出与续写按列表类型、层级和位置处理。刚输入但尚无正文的数字列表标记有保留字面文本的处理。
- 列表中按 Shift+Enter 在本项内换行，Tab 缩进，Shift+Tab 退级。任务清单的新项不继承上一项的完成状态，点击复选框可修改任务状态。
- 表格中按 Enter 移到下方单元格，位于末行时新增行；Tab、Shift+Tab 在单元格间移动，末格向后移动时可新增行。
- 复制与剪切向剪贴板提供 Markdown 文本和结构化 HTML。粘贴文本按 Markdown 解析，代码块内保留文本；外部 HTML 经清洗后进入编辑器。

## 工具栏与内容插入

可编辑预览的正文上方提供格式工具栏：正文、标题、加粗、斜体、删除线、三类列表、引用、链接和图片；更多块菜单包含较深层级标题与折叠段落。工具按钮作用于原选区，不需要切换编辑模式。

输入 `/` 打开分组插入菜单，可筛选标题、列表、代码块、分隔线、表格、公式、Mermaid、图片和表情。方向键选择，Enter 插入，Escape 关闭。表情使用本地中英文数据搜索与分类，插入普通 Unicode 字符，不加载网络图片。

可编辑预览中的 `[[文档]]`、`[[目录/文档|别名]]` 和带标题片段的文档链接支持项目内补全。相同名称存在多个目标时需使用完整项目相对路径，不自动选择其中一个。索引达到容量边界时会提示未完整；未命中不代表文件不存在。文档导航固定原项目，切换项目后的过期请求不会打开新项目里的同名文件。

普通链接可通过工具栏或链接气泡新增、修改、移除与复制地址；链接气泡也可修改显示文字。文档链接节点可通过左右方向键恢复双括号文字进行编辑。

## 表格、代码与查找替换

- 表格单元格旁提供行列悬浮入口，右键也可打开结构菜单；支持插入、删除行列和删除整表，并保护 Markdown 表头。多格选择按所覆盖的行列处理。
- 在全空数据行开头按 Backspace 删除该行；只剩一行时删除表格。空单元格所在行仍有内容时，Backspace 移到前一格，不跨单元格合并正文。
- 代码块提供可搜索的语言选择与复制按钮。选中多行后，Tab、Shift+Tab 缩进或退级。
- Mermaid 代码下方显示实时预览。渲染按需加载并限制资源，拒绝内嵌配置与资源加载指令；结果经清洗后放在隔离展示区，不执行图表中的链接或脚本。
- 可编辑预览的查找浮层支持大小写、全词、上一个与下一个匹配，并可展开单个或全部替换。匹配不跨越段落或受保护的原子节点，替换通过编辑事务进入撤销历史；匹配超过预算时不执行截断的“全部替换”。只读降级仍使用只读查找，不提供替换。

## 源码切换与撤销

「源码」用于直接修改 Markdown 标记，也用于处理预览无法安全编辑的语法。切回预览时采用源码编辑器的最新内容。

源码和富文本编辑面各自管理光标与撤销历史，不共享一条统一撤销链。仅切换视图而内容不变时保留编辑器实例；来自源码的新全文替换或磁盘重新载入会重置相应编辑面的历史，保存回执只更新磁盘基线。跨项目切换需要重建富文本编辑面时，恢复草稿正文与选区，不恢复旧实例的撤销历史。

预览修改会同步为源码快照。未修改的原文尽量复用，格式复用失败时可能输出规范化 Markdown，不承诺逐字节保真。无法证明回写后文档语义等价时，会显示原因并拒绝本次同步；保存和主动视图切换需要先完成输入刷新。

## 保存、草稿与磁盘冲突

使用 Cmd/Ctrl+S 显式保存当前文件。预览的输入同步与草稿捕获只更新窗口内状态，不等于已经写入磁盘。

富文本在尝试 Markdown 序列化之前独立捕获结构草稿；即使无法安全回写，也能在同一窗口重新挂载后恢复正文和选区。成功同步后的文本、保存返回后的核对以及面板卸载也会更新草稿状态。草稿不是跨重启持久化记录；当前是否有待保存输入以文件标签的未保存状态为准，不能仅根据有没有文本快照判断。

保存前先刷新预览输入。组合输入尚未结束或无法安全序列化时，不把旧快照当作最新内容保存。保存进行中继续输入的内容仍作为后续修改保留，不因较早的保存返回而被标为已保存。

磁盘文件被外部修改时，未修改的文件可自动重新载入；存在未保存修改时显示冲突，由用户选择覆盖保存或保留编辑内容。覆盖保存会放弃磁盘上的外部修改。

## 导航、图片与公式

- 目录与正文中的锚点链接用于定位小节；标题旁的锚点按钮复制文件路径与标题引用。查找可使用工具栏或 Cmd/Ctrl+F，字号和 Front Matter 显隐只影响展示。
- 可编辑预览中普通点击链接用于放置光标，Cmd/Ctrl+点击才跳转；只读排版中直接点击链接。项目内 Markdown 链接可打开文件标签，外部网页交由系统浏览器处理。
- 图片仅通过项目文件读取边界加载，不加载远程图片或越界路径。富文本中双击已加载图片放大，只读排版中单击放大。
- 工具栏选图、斜杠菜单选图与粘贴图片会将资源导入所属 Markdown 的同级目录，再插入相对引用；主进程校验来源、格式、大小与目标路径，生成新文件名，不覆盖原图或已有文件。正文仍需显式保存。
- 导入目标随原选区映射，不改用后来移动的光标。文件切换、重载或目标删除后停止插入；资源已经生成时会告知位置，编辑面切走后的反馈随原文件标签保留。撤销正文插入不自动删除图片文件。
- 公式可双击修改，或选中公式节点后按 Enter 打开源码输入。点击「应用」更新文档，取消则放弃该次公式输入。
- Front Matter 在预览中只显示，在源码中修改。

## 只读与降级边界

不支持安全往返的语法、富文本初始化或源码替换失败时，预览保留只读展示并显示原因；只读渲染也失败时显示原文。文件本身允许编辑时，可切到源码修改。编辑过程中的安全回写失败则保留错误提示并阻止本次同步，不代表磁盘已保存。

超过排版预算的文档在解析前回退源码。超过文件可编辑上限的文本不允许编辑或保存，回退源码也不会解除只读限制。

排版预算与可编辑语法判定分别以 `src/renderer/src/editor/file-markdown.ts`、`src/renderer/src/editor/file-rich-markdown.ts` 的定义为准；文件读取与保存限制以 `src/shared/project-file-api.ts` 的常量及主进程判定为准。
